- 2026-08-24 D-004 Sentinel receives spec+diff only, fresh instance per loop ← countermeasure for critic agreement drift observed in production multi-agent systems.
- 2026-08-24 D-005 Self-updating markdown memory (lessons/patterns/decisions) ← transparent, diffable, version-controlled compounding; vector DB rejected as premature for this scale.
- 2026-08-24 D-006 Benchmark-first ordering for detector work (P0′ scored Argus_Master before building anything) ← vindicated: system measured at chance (fused AUC 0.507); weeks of integration effort on an unmeasured base avoided.
- 2026-08-24 D-007 Supervised probes prioritized over one-class for known-generator detection; one-class retained for open-set/unknown-generator duty ← P0 evidence: DINOv2-kNN realness at chance (0.469) while literature shows ≥0.9 AUC from same features with supervised heads.
- 2026-08-24 D-008 Fake corpus generated locally (SD1.5 on MPS) instead of paid image APIs ← free, reproducible, seeds the pseudo-fake engine; 150 imgs @20 steps sufficient for baseline AUC CI ±0.06.
- 2026-08-24 D-009 Learned modules register at harness level (--with-learned), never by editing vendored Argus_Master files ← vendor stays pristine for upstream merges; module contract does the integration work.
- 2026-08-24 D-010 Multi-view feature extraction (clean+jpeg75+resize75 per image) is the default robustness recipe for probe training ← gave free laundering invariance (0.999 AUC held across all rungs).
- 2026-08-24 D-011 Cross-generator eval via locally generated architecturally-diverse families (SANA, SDXL) ← public multi-generator sets are gated/stale/misremembered (CiFAKE=SD1.4-only); local generation is reproducible and auditable.

- 2026-08-24 D-013 P6 fusion = HistGBM+sigmoid stacker on {evidence,reliability}×modules + capacity, trained on train-side dumps only; replaces WeightedVotingJudge via their pluggable judge interface ← beat voting on every set and dropped court abstention 1.00→0.01.

- 2026-08-24 D-018 Multi-domain face training {Celeb-DF + WildDeepfake-train} ← replicated the SANA law on faces: WildDeepfake exam 0.802→0.906 while Celeb-DF held ≥0.98; deployed as artifacts/p3_full/face_probe.joblib (court default).

- 2026-08-24 D-021 Stacker training sets MUST include score dumps from every domain its member probes serve ← face-head votes were silently ignored (feature always zero in scene-image dumps) until cdf face-crop rows joined the stacker diet; fused verdict flipped 0.045→0.972 on synthesis faces with zero AIGC regression.

- 2026-09-02 D-024 Per-domain heads beat joint training on EVERY cell of the transfer matrix ← ffpp-only specialist: FF++ 0.8885 in-domain (beats joint 0.8681) with zero-shot CDF/Wild 0.790/0.786; deployed p3_full: CDF 0.982/Wild 0.906 with zero-shot FF++ 0.728. Architecture: keep p3_full for court default; promote FF++ only as an ADDITIONAL evidence channel via the P6 stacker (stacker learns per-domain reliability, no explicit router needed).
