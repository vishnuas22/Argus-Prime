# V1c-2 / V1d-2 — research outcome (2026-11-21)

## 1. V1c-2 (image-court on T2V frames) — **NEGATIVE, rejected**

Hypothesis: the image court (11 forensic channels, near-perfect on generated
IMAGES) applied to sampled T2V *frames* would beat the face pipeline (AUC 0.653).

Smoke test: 20 ASMR clips (10 real + 10 fake) × 3 frames through `detect_image`.

| Metric | Value |
|---|---|
| clip-level `p_max` AUC | **0.6400** (n=20) |
| clip-level `p_mean` AUC | **0.4700** (below chance) |
| fake catch (p_max≥0.5) | 3/10 = **30%** |
| real FPR (p_max≥0.5) | 2/10 = **20%** |

**Verdict:** 30% catch at **20% FPR** is *worse* than the incumbent face pipeline
(27.7% catch at **4.8%** FPR). D-121's "content artifact" call on the V1f
`image_court` route was correct. **Rejected — no contribution.**

Caveat: n=20 means CI ≈ ±0.25, so this is "no signal detected", not "no signal
exists". But the FPR is clearly unacceptable, so a full run is not justified.

## 2. New candidate for V1d-2 — **frozen video-SSL (V-JEPA2) + linear probe**

### Why this is genuinely new
Everything the repo has tried on the video lane is in one of these families:
CLIP face probes · DINOv2 image probes (D3/ReStraV/P7) · SBI/SCENE image-blend ·
temporal statistics (SPLIT/WaveRep) · SyncNet AV.

**Never tried: video-native self-supervised features.** V-JEPA models motion
natively instead of per-frame, and no frozen-SSL *video* backbone has been
probed in this repo.

### Evidence it can work (published, 2025–2026)
| Source | Result |
|---|---|
| arXiv 2606.26384 (audit, frozen SSL) | frozen-SSL + **linear probe** approaches specialised detectors across image/audio/video; **V-JEPA2 ViT-G** used on AIGVDBench (440k videos, 31 generators) |
| arXiv 2611.21846 (**2026-11-16**, 5 days old) | V-JEPA 2.1 frozen + rank-16 LoRA predictor, **8.25M trainable (2.47%)**; trained on FF++ only → **AUC 0.905 on Celeb-DFv2** |
| arXiv 2607.13234 (BMF) | V-JEPA 2 encoder is "the only component that models motion natively"; GenVidBench **0.918**, GenVideo-100K **0.924** |
| arXiv 2606.31004 (6-control audit) | after confounds removed, a **motion-content detector holds at 0.832** on GenVidBench; D3/ReStraV/WaveRep audited |

### What the audits say about our own numbers
arXiv 2606.31004 is a direct independent confirmation of D-121:
- a **3-feature clip-length classifier scores 0.998 AUC** on GenVidBench under
  unaudited evaluation (pure confound)
- after controls it **falls to chance 0.529**
- "a CLIP appearance baseline is caught carrying dataset identity"

**So our OOD-video numbers (0.60–0.75) are confounded in exactly the way the
literature now measures.** That validates closing the rescore path.

### Cheapest pilot (proposed, not started)
- V-JEPA2 ViT-B/16 or ViT-L/16 frozen (avoid ViT-G, too big for CPU)
- 8 frames per clip, frozen features → linear probe
- Train on existing FF++ labels, evaluate on **CDF** (already on disk)
- Bar: CDF AUC ≥ p6vid_v4's **0.9482** with a linear probe
- Cost: model download (~1–2 GB) + ~30 min CPU inference on ~500 clips

**Risk:** V-JEPA2 ViT-G is the strong variant; ViT-B/L may be much weaker. Must
pilot the small variant before committing.

## 3. Recommended next item

**V1d-2: frozen V-JEPA2 + linear probe pilot.**

Reasons:
1. **Only genuinely new signal class** left for the one dimension that can reach 70.
2. **Cheap to falsify** — a linear probe on frozen features is a hours-scale
   experiment, not a training programme.
3. **Published evidence is strong and recent** (90.5 CDF from FF++ training, 5
   days old), unlike the closed candidates.
5. **Falsification bar is pre-registerable**: if frozen V-JEPA2-B/L cannot beat
   p6vid_v4 on CDF, the line closes at 0 cheaply.

### Rejected alternatives
- **S1-promote** — crashes; throughput only; no detection gain.
- **p6vid_v5-on-SFace** — commercial enabler, but **0 detection Y** (D-123).
- **V1c full run** — image-court smoke already failed (20% FPR).
- **R1/R2/AB1/AB2/MM1** — all previously closed or low-P.
- **D1/D2/D3 data** — data alone does not detect; D-105 gated.
